📖 Chapter 4 — Microsoft Entra ID & Identity Solutions
Microsoft Entra ID Concepts
🔹 1. Microsoft Entra ID
📖 Definition
Microsoft Entra ID (formerly Azure Active Directory) is Microsoft's cloud-based identity and access management service.
🌍 Example
It manages employee accounts for Microsoft 365.
⭐ Remember This
Entra ID = Cloud Identity Management
________________________________________
🔹 2. Azure Active Directory (Old Name)
📖 Definition
Azure Active Directory was renamed to Microsoft Entra ID.
⭐ Remember This
Azure AD = Microsoft Entra ID
________________________________________
🔹 3. Tenant
📖 Definition
A dedicated Microsoft Entra ID instance for an organization.
🌍 Example
Each company has its own tenant.
⭐ Remember This
Tenant = Organization's private cloud identity space.
________________________________________
🔹 4. User Account
📖 Definition
An account created for an individual user.
🌍 Example
An employee logs into Microsoft 365 using their Entra ID account.
________________________________________
🔹 5. Group
📖 Definition
A collection of users managed together.
🎯 Benefit
Permissions can be assigned to the entire group instead of individual users.
________________________________________
🔹 6. Device Identity
📖 Definition
A registered device recognized by Microsoft Entra ID.
🌍 Example
A company laptop joined to Entra ID.
________________________________________
🔹 7. Microsoft Entra Join
📖 Definition
Registers a device directly with Microsoft Entra ID.
🌍 Example
A cloud-managed company laptop.
________________________________________
🔹 8. Hybrid Join
📖 Definition
A device connected to both on-premises Active Directory and Microsoft Entra ID.
🌍 Example
A company using both local servers and cloud services.
________________________________________
🔹 9. Registered Device
📖 Definition
A personal device registered with Entra ID.
🌍 Example
An employee registers their personal mobile phone.
________________________________________
🔹 10. Self-Service Password Reset (SSPR)
📖 Definition
Allows users to reset their own passwords without IT support.
🌍 Example
Resetting a forgotten Microsoft password using phone verification.
🎯 Benefit
Reduces IT workload.
________________________________________
🔹 11. Microsoft Authenticator
📖 Definition
An authentication app used for MFA and passwordless login.
🌍 Example
Approving login requests through the Microsoft Authenticator app.
________________________________________
🔹 12. Password Protection
📖 Definition
Blocks weak or commonly used passwords.
🌍 Example
Preventing users from choosing "12345678".
________________________________________
🔹 13. Identity Protection
📖 Definition
Detects risky users and suspicious sign-in activities.
🌍 Example
Login attempt from another country.
🎯 Benefit
Automatically blocks or requires MFA.
________________________________________
🔹 14. Risk-Based Authentication
📖 Definition
Authentication requirements change according to login risk.
🌍 Example
Normal login → Password only.
Suspicious login → Password + MFA.
________________________________________
🔹 15. B2B (Business-to-Business)
📖 Definition
Allows external business partners to access company resources securely.
🌍 Example
A vendor accesses a shared Microsoft Teams workspace.
________________________________________
🔹 16. B2C (Business-to-Consumer)
📖 Definition
Allows organizations to manage customer identities.
🌍 Example
Customers signing into an online shopping website.
________________________________________
🔹 17. Federation
📖 Definition
Allows users to access different systems using trusted identities.
🌍 Example
Logging into multiple services with the same organizational account.
________________________________________
🔹 18. Identity Synchronization
📖 Definition
Keeps identities synchronized between on-premises Active Directory and Microsoft Entra ID.
🎯 Benefit
Same credentials work in both environments.
________________________________________
🔹 19. Cloud Authentication
📖 Definition
Authentication performed directly by Microsoft Entra ID.
🌍 Example
Logging into Microsoft 365 from anywhere.
________________________________________
🔹 20. Access Reviews
📖 Definition
Regularly checking whether users still need their assigned permissions.
🌍 Example
Reviewing guest accounts every three months.
________________________________________
